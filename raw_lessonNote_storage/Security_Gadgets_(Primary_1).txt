Introduction 2. Meaning and Examples of Security Gadgets 3. Uses of Security Gadgets 4. Revision and Weekly Assessment (Test) LEARNING OBJECTIVES By the end of the lesson, most of the pupils should have attained the following objectives – 1. explain the meaning of security gadgets. 2. give examples of security gadgets. 3. state the uses of security gadgets. LEARNING BEHAVIOURS The pupils can identify and describe a camera. INSTRUCTIONAL MATERIALS The teacher will teach the lesson with the aid of chart showing different security gadgets. METHOD OF TEACHING Choose a suitable and appropriate methods for the lessons. Note – Irrespective of choosing methods of teaching, always introduce an activities that will arouse pupil’s interest or lead them to the lessons. REFERENCE MATERIALS 1. Scheme of Work 2. 9 – Years Basic Education Curriculum 3. Course Book 4. All Relevant Material 5. Online Information CONTENT OF THE LESSON LESSON 1 – INTRODUCTION MEANING OF SECURITY GADGETS 1. Security gadgets are devices used to prevent unauthorized persons from gaining access to restricted areas. For example, security doors, locked, cabinet, etc. 2. Security gadgets can also be used to monitor or track unexpected crime or criminal. For example – cameras, tracker, etc. 3. Security gadgets are also used detect unwanted objects coming into a private property. For example – scanners and alarm. EXAMPLES OF SECURITY GADGETS The following are the examples of security gadgets, 1. Security Cameras 2. Security locked 3. Security doors 4. Security cabinets 5. Security alarms 1. SECURITY CAMERA A security camera is a gadget used in or outside a building to record the activities of people within and around. 2. SECURITY LOCK A security lock is a gadget used to protect people and other valuable items such as money, documents, jewelries, etc. Security lock can be used at the door, drawer, or case. 3. SECURITY DOOR Security door is a gadget used to prevent unwanted visitors from gaining access in a building or apartment. Security door is made of steel or wrought iron. 4. SECURITY CABINET A security cabinet is a safety box used to keep value items such as documents, jewelries, etc. 5. SECURITY ALARM A security alarm is a gadget used to detect unauthorized entry. LESSON 2 – EXAMPLES OF SECURITY GADGETS 6. Security scanners 7. Security spray 8. Security handcuffs 9. Security shock 10. Security radio 11. Security lights 12. Security guns, etc. 6. SECURITY SCANNER A security alarm is a gadget used to detect unwanted or dangerous objects such as weapon, drugs, etc. 7. SECURITY SPRAY A security spray is a gadget used as defence against any attack. It is commonly used by female to cause temporary blindness and  difficult breathing to the attacker. The spray is made of chemical make from chili peppers. 8. SECURITY HANDCUFFS A security handcuff is a mental locked used to hold someone’s wrist together, mostly during an arrest. It is used to prevent free movement. 9. SECURITY SHOCK A security shock is a gadget used as self defence or force compliance. 10. SECURITY RADIO A security radio or phone is a gadget used to keep in regular touch with controllers and fellow team members. 11. SECURITY LIGHTING A security lighting is a gadget used to discourage or detect criminal activity from taken place on a property or site. 12. SECURITY GUN A security gun is a weapon used for firing bullets. It is used by authorized security personnel. IMPORTANCE OF SECURITY GADGETS The importance of security gadgets are as follows: 1. It is used for safeguarding lives and properties. 2. It is used for self defence. 3. It is used for restrict unwanted guest. 4. It is used for moving valuable items from one place to another. 5. It is used arresting and detailing criminals. 6. It is used for detecting unwanted materials or weapons, etc. PRESENTATION To deliver the lesson, the teacher adopts the following steps: 1. To introduce the lesson, the teacher revises the previous lesson. Based on this, he/she asks the pupils some questions; 2. Teacher organized the pupils into groups or pairs depending on the size of the size and available instructional materials. 3. Teacher lets pupils in groups or pairs to identify and describe the gadgets. Pupil’s Activities – Learners identify and describe each security gadgets. 4. Teacher asks pupils to mention people that use the listed gadgets. Pupil’s Activities – Learners describe the duties and responsibilities of a security guard. 5. Teacher listens to the groups or pairs and uses their relevant responses to introduce the lesson. Pupil’s Activities – Learners pay attention to the lesson introduction to understand the concept of the lesson. 5. Teacher uses the chart to lead a discussion on the meaning of security gadgets. Pupil’s Activities – Learners participate actively in the class discussion and analyze the importance of security gadgets in their communities. 6. Teacher invites security personnel to discuss the importance of security gadgets. Pupil’s Activities – Learners pay attention to the invited guest for questions and answers. 7. Teacher summarizes the lessons on the board with appropriate lesson evaluation. Pupil’s Activities – Learners participate actively in the summary of the lesson by responding correctly to questions and write as instructed. CONCLUSION To conclude the lesson for the week, the teacher revises the entire lesson and links it to the following week’s lesson.
