Lesson Evaluation and Weekly Assessment (Test) PERFORMANCE OBJECTIVES By the end of the lesson, most of the pupils should have attained the following objectives (cognitive, affective and psychomotor) and be able to – 1. Identify system unit. 2. List internal features of a system unit. 3. State the uses of each of these features. INSTRUCTIONAL MATERIALS The teacher will teach the lesson with the aid of: 1. Functional computer systems. 2. Different types of system units. 3. Chart shows different parts of system unit – Internal Features METHOD OF TEACHING Choose a suitable and appropriate methods for the lessons. Note – Irrespective of choosing methods of teaching, always introduce an activities that will arouse pupil’s interest or lead them to the lessons. REFERENCE MATERIALS Scheme of Work 9 – Years Basic Education Curriculum Course Book All Relevant Material Online Information CONTENT OF THE LESSON LESSON 1 – INTRODUCTORY ACTIVITIES Activity 1 Teacher’s Activities – Display a functional computer (if available) or a chart showing a computer for the pupils to identify the system unit. Pupil’s Activities – This is a system unit. Teacher’s remark – Good job you. A system unit is the main part of a computer. The system Unit counts, calculates and stores what we type into the computer. We can make use of what is stored in the system when it is needed. System Unit has two main features – external features (as we discussed in our previous lesson) and internal features. Today, we are going to learning the internal features of a system unit and how its function. ACTIVITY 2 Teacher’s Activities – Open the case of a system unit (if available) or chart showing the internal features of a system unit, let the pupils visualize the features of the unit. Pupils Activities – Observe the internal connection between the internal system unit. Teacher’s remark – A great cheer for the pupils. Comment and list the internal feature of a system unit on the board. INTERNAL FEATURES OF SYSTEM UNIT The internal features of system unit are – 1. CPU – Processor 2. Disk drives (hard disk drive, floppy disk drive, CD – ROM Drives). 3. Motherboard 4. Main memory 5. Power supply Note – Guide the pupils to cover and screw back the system unit. LESSON 2 – INTRODUCTORY ACTIVITIES (PRACTICAL) Teacher’s Activities – Disconnect some of the internal features, power it and ask the pupils to ON the system unit if it ON or connected to other components. Note – Please, proceed with caution. Pupil’s Activities – The computer is not booting or coming on. Teacher’s remark – Comment and connect each feature one by one to let the pupils understand the uses of each feature. Ask and summary the uses of internal features on the board. USES OF INTERNAL FEATURES OF SYSTEM UNIT 1. CPU CPU stands central processing unit. It is known as computer brain. It sends signals that control other parts of the computer. 2. Disk drives (hard disk drive, floppy disk drive, CD – ROM Drives) Disk drive is a device that allows a computer to read from and write on to computer disks 3. Motherboard The motherboard or mainboard is the main circuit board that connects other internal features of a system unit. 4. Main memory RAM is the main memory of a computer and it is generally known as RAM. It is part of internal features that stores operating system and other software. 5. Power supply A power supply is the device that supplies electricity power to the computers. ASSIGNMENT Find out the meaning of storage device. PRESENTATION To deliver the lesson, the teacher adopts the following steps: 1. To introduce the lesson, the teacher revises the previous lesson. Based on this, he/she asks the pupils some questions; 2. Guides pupils to open the system unit. Pupil’s Activities – Open the system unit. 3. Lets them visualize the features of the unit. Pupil’s Activities – Observe the internal connection between the internal system unit. 4. Discuss the internal features of system unit. Pupil’s Activities – Participate actively in the class discussion. 5. Summary of the lesson on the board. Pupil’s Activities – Copy as the teacher write. CONCLUSION To conclude the lesson for the week, the teacher revises the entire lesson and links it to the following week’s lesson.
