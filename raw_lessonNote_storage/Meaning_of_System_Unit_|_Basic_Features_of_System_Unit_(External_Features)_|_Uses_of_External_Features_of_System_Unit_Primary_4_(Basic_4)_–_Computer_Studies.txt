Lesson Evaluation and Weekly Assessment (Test) PERFORMANCE OBJECTIVES By the end of the lesson, most of the pupils should have attained the following objectives (cognitive, affective and psychomotor) and be able to – 1. Identify system unit. 2. List external features of a system unit. 3. State the uses of each of these features. INSTRUCTIONAL MATERIALS The teacher will teach the lesson with the aid of: 1. Functional computer systems. 2. Different types of system units. 3. Chart shows different parts of system unit. METHOD OF TEACHING Choose a suitable and appropriate methods for the lessons. Note – Irrespective of choosing methods of teaching, always introduce an activities that will arouse pupil’s interest or lead them to the lessons. REFERENCE MATERIALS Scheme of Work 9 – Years Basic Education Curriculum Course Book All Relevant Material Online Information CONTENT OF THE LESSON ONE LESSON 1 – INTRODUCTORY ACTIVITIES Teacher’s Activities – Display a functional computer (if available) or a chart showing a computer for the pupils to identify the system unit and its external features such as where the monitor, mouse, printer, scanner, etc.are connected. Pupil’s Activities – This is a system unit. Monitor is connected here,…. Teacher’s remark – Good job you. Discuss the meaning and main external features of system unit and summary on the board. MEANING OF SYSTEM UNIT A system unit is the main part of a computer which includes the motherboard, CPU, RAM, and other components. The system unit also includes the case that houses the internal components of the computer. There are two (2) types of system unit, internal and external features. EXTERNAL FEATURES OF SYSTEM UNIT (FRONT FEATURES) 1. Power button 2. Power light 3. Reset button 4. CD/DVD – ROM drive 5. Floppy disk drive 6. USB ports 7. Key lock LESSON 2 – INTRODUCTORY ACTIVITIES Teacher’s Activities – Group the pupils based on the available computer systems (if available). Lead and guide them to identify the uses external features of system unit. Pupil’s Activities – Participate in the group activities and follow the teacher’s instructions. Teacher’s remark – Give a cheer and comment. Ask the pupils, what is the use of – USES OF EXTERNAL FEATURES OF SYSTEM UNIT 1. Power button It is used to switch On/Off a computer system. 2. Power light It is an indicator that show if the system is power is on or off. 3. Reset button It is used to restart a computer system. 4. CD/DVD – ROM drive It is used for installing software or playing music or movie. 5. Floppy disk drive It is used for storing data on external drive. 6. USB ports It is used for connecting external drive to the computer system. It is also used for send date into the computer system. 7. Key lock It is used to prevent anyone from accessing the computer when he/she is absent. PRESENTATION To deliver the lesson, the teacher adopts the following steps: 1. To introduce the lesson, the teacher revises the previous lesson. Based on this, he/she asks the pupils some questions; 2. Asks the pupils, what parts of computer system is this? Pupil’s Activities – Answer the teacher’s question. 3. Guides them to compare and identify common features of different system units. Pupil’s Activities – Compare and identify common features of different system units. 4. Guides pupils to operate each of the front features of system unit. Pupil’s Activities – Operate each of the front features of system unit. 5. Summary the lesson on the board. Pupil’s Activities – Copy as the teacher writes. CONCLUSION To conclude the lesson for the week, the teacher revises the entire lesson and links it to the following week’s lesson.
