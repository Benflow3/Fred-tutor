###Security Education | Primary/Basic 1 | First Term
Week: 1
Topic: Concept of Security
Objectives: By the end of the lesson; pupils should be able to: i. define the meaning of security; ii. describe how a security personnel looks like.
Week: 2
Topic: Concept of security
Objectives: By the end of the lesson; pupils should be able to: i. mention security facts e.g. do not take anything from a stranger. ii. do not follow a stranger e.t.c.; iii. discuss strangers tactics.
Week: 3
Topic: Sources of Insecurity
Objectives: By the end of the lesson, pupils should be able: i. mention sources of insecurity. e.g -A dilapidated building -Filling station with no fire extinguisher.
Week: 4
Topic: Security- Alert signs
Objectives: By the end of the lesson; pupils should i. explain the security alert signs ii. list and discuss the consequences of neglecting signs of security alert
Week: 5
Topic: Security colours
Objectives: By the end of the lesson, pupils should be able to: i. mention the security colours and meaning e.g Red, yellow, Blue, Green and Orange. ii. discuss the meaning of colours.
Week: 6
Topic: Security Gadget
Objectives: By the end of the lesson, pupils should be able to: i. List security gadget e.g. Camera, CCTV, microphone.
Week: 7
Topic: MIDTERM TEST/BREAK
Objectives: MIDTERM TEST/BREAK
Week: 8
Topic: Office Security
Objectives: By the end of the lesson pupil should be able to: (l) mention home security tips e.g. Locking the doors, Flood light, detector e.t.c
Week: 9
Topic: Office Security
Objectives: By the end of the lesson, pupils should be able to: i. mention the security measures to be taken in offices e.g locking doors, putting all electrical appliances off.
Week: 10
Topic: Personal Security
Objectives: By the end of the lesson; pupils should be able to : i. define personal security, ii. list components of personal security at home, school, on the road etc
