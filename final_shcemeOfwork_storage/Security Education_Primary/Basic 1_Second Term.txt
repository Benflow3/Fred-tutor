###Security Education | Primary/Basic 1 | Second Term
Week: 1
Topic: SECURITY PRECAUTION
Objectives: By the end of the lesson, pupils should be able to: i. mention the security precautions; ii. discuss the security precautions.
Week: 2
Topic: Identify Sources of Danger
Objectives: By the end of the lesson, pupils should be able to: i. define sources of danger;
Week: 3
Topic: SECURITY PRECAUTION ON THE ROAD.
Objectives: By the end of the lesson/ pupils should be able to: i. identify some road signs and meaning.
Week: 4
Topic: SECURITY PRECAUTION AT HOME.
Objectives: By the end of the lesson , pupils be able to: i. state security precautions to be taken at home; e.g. locking the door, keeping dangerous away from children e.g. Matches and Drugs.
Week: 5
Topic: SECURITY PRECAUTION IN THE OFFICE
Objectives: By the end of the lesson pupils should be able to: i. mention precautionary measures that should be taken in the office.
Week: 6
Topic: SECURITY PRECAUTIONS
Objectives: By the end of the lesson, pupils should be able to: i. State personal security measures. ii. Identify the type of Adult to attend to i.e ” not following a sttanger” iii. discuss why personal security precaution is necessary.
Week: 7
Topic: MID TERM TEST/MIDTERM BREAK
Objectives: MID TERM TEST/MIDTERM BREAK
Week: 8
Topic: SECURITY PRECAUTION IN THE SCHOOL
Objectives: By the end of the lesson: pupils should be able to ; i. mention security precautions to be taken in school ii. describe the security precautions in the school e.g. not walking alone, not playing with harmful objects e.t.c
Week: 9
Topic: Precautions in the car/buses
Objectives: By the end of the lesson, pupils should be able to; i. mention the security measures to be taken in the car/buses; ii. describe the danger attached to a child sitting in the front seat. iii. explain how seat belt looks like.
Week: 10
Topic: General security tips
Objectives: By the end of the lesson, pupils should be able to; (i) mention important security tips e.g. knowing emergency numbers, not playing with sharp object. ii. Describe some other security tips.
Week: 11
Topic: Security precaution in the environment
Objectives: By the end of the lesson, pupils should be able to; i. mention the precaution to be taken in time of flood ii. describe the precaution to be taken in time of the fire outbreak, road accident e.t.c
Week: 12
Topic: REVISION AND EXAMINATION
Objectives: REVISION AND EXAMINATION
